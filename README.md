# Задание 5 — управление объектом в WebAR

Продолжение задания 4: размещение объекта на найденной поверхности и управление им.

## Возможности

- Куб, сфера и тор; переключение сохраняет положение, цвет и поворот.
- Выбор цвета, поворот на 15° и автоповорот.
- MeshStandardMaterial с настройками roughness и metalness.
- Environment map: RoomEnvironment → PMREMGenerator → scene.environment.
- HTML UI внутри WebXR DOM Overlay; beforexrselect предотвращает размещение при нажатии на элементы управления.
- Предпросмотр в обычном браузере без запуска AR.

## Запуск

Из папки проекта: `python3 -m http.server 8000`, затем http://localhost:8000.
Для AR на телефоне нужен HTTPS и поддержка immersive-ar, hit-test, dom-overlay.
Локальный HTTP по IP компьютера для AR не подходит.

GitHub Pages: загрузить содержимое папки в корень репозитория, Settings → Pages → Deploy from a branch → main → /(root) → Save.
Сборка npm не требуется. Все зависимости лежат локально в vendor.

## Проверка на телефоне

Открыть HTTPS-сайт в совместимом браузере, нажать «Открыть AR», разрешить камеру.
Навести камеру на поверхность, дождаться кольца, нажать вне панели.
Проверить форму, цвет, вращение и материалы. Нажатия на панель не должны перемещать объект.
Выйти из AR и запустить повторно.
Фактическую работу камеры и поиска поверхностей необходимо проверить на устройстве.

## Модули

- App — сцена, камера, рендер и цикл кадров.
- SceneObject — геометрии, PBR-материал, трансформации.
- Environment — освещение environment map.
- ARController — сессия, hit-test и размещение.
- UI — DOM-элементы и обработка событий.
